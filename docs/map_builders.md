# MapBuilders

The `MapBuilder` class provides an easy to use interface for building maps. The SunoBot code provides 3 variants of MapBuilders: `MapBuilder`, `AdvancedMapBuilder`, and `SemanticMapBuilder`. Intuitively, these variants build a `Map`, `AdvancedMap`, or `SemanticMap` respectively.
